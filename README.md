# School-management-system-java
A beginner-friendly School Management System built with Java, OOP, Array List, and CRUD operations.

## About the Project
This project is a simple console application that allows users to manage student and teacher records.

The system provides options to add, view, update, and delete records.

## Features
### Student Management

- Add student
- View students
- Update student information
- Delete student

### Teacher Management

- Add teacher
- View teachers
- Update teacher information
- Delete teacher

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Switch Statement
- While Loop
- CRUD Operations

## OOP Concepts Used

- Classes and Objects
- Constructors
- Object Creation
- Object References

## How the Program Works

When the program starts, it displays the main menu:

1. Manage Student
2. Manage Teacher
3. Exit

The user can select an option and manage student or teacher records through the console.

## Student Operations

1. Add Student
2. View Students
3. Update Student
4. Delete Student
5. Exit

## Teacher Operations

1. Add Teacher
2. View Teachers
3. Update Teacher
4. Delete Teacher
5. Exit
